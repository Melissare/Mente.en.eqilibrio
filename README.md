# Mente en Equilibrio
Página educativa e interactiva sobre hábitos digitales saludables.

## Archivos
- `index.html`: estructura de las cuatro pestañas.
- `style.css`: diseño adaptable, tarjetas, colores y animaciones.
- `script.js`: navegación, autoevaluación, filtros y mini quiz.

## Cómo abrir
Abre `index.html` en un navegador. Para editar, abre la carpeta completa en Visual Studio Code.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `mente-en-equilibrio`.
2. Sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz.
3. Ve a Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Elige la rama `main` y carpeta `/(root)`, luego Save.
6. Espera a que GitHub muestre el enlace publicado.

## Nota importante
Es un recurso educativo de bienestar digital, no una herramienta médica. No diagnostica ni afirma que las redes sociales causen deterioro cognitivo. Los hábitos sugeridos pueden apoyar una rutina equilibrada, pero no garantizan prevenir enfermedades.
